
# Event Discovery App

An event discovery website that helps users explore events and activities based on their location and interests. It integrates external APIs to retrieve and display relevant events across different categories.

## Features

- Discover events based on location
- Browse events by categories
- Search and explore events
- Location-based event recommendations
- Display event details
- Explore nearby activities and events
- Responsive user interface
